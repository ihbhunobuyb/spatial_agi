## 摘要摘要 (Abstract Summary)

Theory of Mind (ToM) reasoning with Large Language Models (LLMs) requires inferring how people's implicit, evolving beliefs shape what they seek and how they act under uncertainty -- especially in high-stakes settings such as disaster response, emergency medicine, and human-in-the-loop autonomy. Prior approaches either prompt LLMs directly or use latent-state models that treat beliefs as static and independent, often producing incoherent mental models over time and weak reasoning in dynamic contexts.

**核心贡献**:
1. 提出了一种结构化认知轨迹框架，使用动态信念图表示心智状态
2. 设计了语义到势能的投影（Semantic-to-Potential Projection），将LLM的语义证据映射到一元和成对势函数
3. 引入了带动作特定自注意力的动作模型，捕捉信念与动作之间的非线性交互
4. 推导了基于ELBO的变分学习目标，联合学习投影、信念图势函数和动作模型

## 1. 研究背景与问题定义

### 1.1 Theory of Mind (ToM) 概述

Theory of Mind (心智理论) 是心理学和认知科学中的核心概念，指的是推断他人隐性心理状态（如信念、意图、欲望）的能力，并利用这些推断来解释和预测行为。这一能力在以下场景中尤为重要：

- **灾难响应**: 推断居民的疏散决策背后的风险感知
- **急诊医疗**: 理解患者对治疗方案的选择
- **人机协作**: 预测人类在自动驾驶场景中的行为

### 1.2 现有方法的局限性

论文指出当前ToM推理方法的三个主要问题：

1. **信念被视为静态**: 传统方法将信念视为独立且不变的变量，忽略了信念随时间演化的特性
2. **信念间独立性假设**: 假设不同信念之间相互独立，忽略了信念之间的相互依赖关系（如风险感知的相互强化或抑制）
3. **缺乏行为约束**: 推断出的信念与观察到的行为之间缺乏因果联系，导致信念可能是"事后合理化"而非真正的行为解释

### 1.3 核心挑战

在**高风险决策环境**中，这些问题尤为突出：

- **灾难疏散**: 居民的风险感知会随新观察（如看到火焰、收到疏散令）而快速变化
- **信念间交互**: 多个风险感知相互影响（有的会强化，有的会抑制）
- **延迟动作**: 信念积累到一定程度才触发行动，动作稀疏且延迟

### 1.4 问题形式化

论文将人类认知建模为序贯决策过程：

- **环境状态 st**: 环境的潜在物理状态（如灾难强度或接近程度）
- **观察 ot**: 智能体在时间t收到的文本描述（如"收到疏散令"）
- **信念状态 bt**: 智能体的认知状态，定义为结构化二进制信念向量 bt = [bt,1, ..., bt,K] ∈ {0,1}^K
- **动作 at**: 智能体在时间t选择的行为

## 2. 核心算法原理 (Q1)

### 2.1 整体框架概述

论文提出的框架称为**Structured Cognitive Trajectory Modeling**，其核心思想是：

1. 将心智状态表示为**动态信念图**（Dynamic Belief Graph）
2. 使用LLM提供语义嵌入，将语言证据投影到概率图模型
3. 通过能量函数（Energy Function）建模信念间的依赖关系
4. 使用ELBO目标函数联合学习所有组件

### 2.2 语义到势能投影 (Semantic-to-Potential Projection)

#### 2.2.1 信念嵌入提取

对于每个信念维度i，论文使用冻结的LLM（Qwen-8B）提取语义嵌入：

**构建两种提示变体**（仅在前一个信念状态假设不同）：
- 假设前一个信念存在：bt-1,i = 1 ("Yes")
- 假设前一个信念不存在：bt-1,i = 0 ("No")

```python
h_yes = LLM(bt,i | ot, bt-1,i = 1)  # 信念存在时的嵌入
h_no = LLM(bt,i | ot, bt-1,i = 0)  # 信念不存在时的嵌入
```

#### 2.2.2 历史信念融合

为了将历史信息融入当前证据提取，使用上一时间步的信念边际概率进行期望：

```python
h_tilde_i = p(belief_i at t-1) * h_yes + (1 - p(belief_i at t-1)) * h_no
```

这确保了语义证据提取考虑了信念的时间连续性。

#### 2.2.3 一元势能函数 (Unary Potential)

由于信念状态不可观察，一元势能需要通过无监督方式学习。为防止语义翻转（flipping），论文使用对比学习将能量与LLM的语义方向对齐：

```python
# 基础一元分数：通过余弦相似度对比
phi_base = tau * cos(h_yes, h_no_ref) - cos(h_no, h_yes_ref)

# 残差学习：捕获对比对齐无法解释的偏差
phi = phi_base + w_u * ReLU(h_tilde) + beta_u
```

#### 2.2.4 成对势能函数 (Pairwise Potential)

为建模信念间的交互，论文设计了成对嵌入：

```python
h_ij = LLM(belief_i, belief_j)  # 成对语义嵌入
phi_ij = w_p^T * ReLU(h_ij) + beta_p
```

- phi_ij > 1: 鼓励信念i和j共同激活（相互强化）
- 0 < phi_ij < 1: 阻止共同激活（相互抑制）

### 2.3 信念转移先验 (Belief Transition Prior)

#### 2.3.1 吉布斯分布

给定前一个信念状态和当前观察，信念转移先验定义为所有2^K种信念配置上的吉布斯分布：

```python
E_theta(b_t) = sum_i log(phi_i(b_t,i)) + sum_{i<j} log(phi_ij(b_t,i, b_t,j))

p_theta(b_t | b_{t-1}, o_t) = exp(E_theta(b_t)) / Z_q(b_{t-1}, o_t)
```

其中Z_q是配分函数，用于归一化分布。

#### 2.3.2 边际信念概率

通过枚举所有联合信念配置计算边际信念概率：

```python
p(b_t,i = 1 | b_{t-1}, o_t) = sum_{b_t: b_t,i=1} p_theta(b_t | b_{t-1}, o_t)
```

### 2.4 动作生成模型 (Action Model)

#### 2.4.1 信念条件动作嵌入

对于每个动作j，论文预计算两种信念条件下的动作嵌入：

```python
e_{j,i}^{(1)} = LLM(action_j | belief_i = 1)  # 信念存在时的动作嵌入
e_{j,i}^{(0)} = LLM(action_j | belief_i = 0)  # 信念不存在时的动作嵌入
```

使用边际信念概率混合：

```python
x_{t,j,i} = p(b_t,i = 1) * e_{j,i}^{(1)} + (1 - p(b_t,i = 1)) * e_{j,i}^{(0)}
```

#### 2.4.2 动作特定自注意力

论文指出不同信念组合会以非线性方式触发不同动作，因此使用自注意力建模信念间的交互：

```python
# 自注意力计算
A_{t,j} = softmax(Q_{t,j} * K_{t,j}^T / sqrt(d_k))

# Q, K, V是X_{t,j}的线性投影
Z_{t,j} = A_{t,j} * V_{t,j}
```

注意力矩阵A_{t,j}[i,k]量化了信念k如何调节信念i对动作j决策表示的贡献。

#### 2.4.3 动作似然

使用聚合的信念特征参数化动作似然：

```python
logit_{t,j} = W_1 * ReLU(u_inf_{t,j}) + b_1
p(a_t | b_t) = softmax(logit_{t,j})
```

其中u_inf_{t,j} = LLM(belief_j | o_t, a_t)是结合观察和动作的信念特定语义嵌入。

### 2.5 变分推断与ELBO目标

#### 2.5.1 推理模型

由于信念bt不可观察，论文引入变分近似后验：

```python
q_phi(b_t | o_t, a_t) = product_i q_phi(b_{t,i} | u_inf_{t,i})
```

推理模型允许条件于实际动作at，而生成先验不允许。这种不对称性使推理网络可以利用后见之明来产生更准确的后验估计。

#### 2.5.2 ELBO推导

目标函数是每时间步ELBO的总和：

```python
# 动作重构项
L_action = E_{q(b_t|o_t,a_t)} [log p_theta(a_t | b_t)]

# KL正则化项
L_KL = KL(q_phi(b_t | o_t, a_t) || p_theta(b_t | b_{t-1}, o_t))

ELBO = L_action - L_KL
```

#### 2.5.3 训练与测试

- **训练时**: 使用推理模型q_phi近似后验，优化ELBO
- **测试时**: 仅使用生成组件p_theta(b_t | b_{t-1}, o_t)和p_theta(a_t | b_t)

### 2.6 算法流程总结

```
输入: 观察序列 o1:T, 动作序列 a1:T
输出: 信念轨迹 b1:T, 动作预测

1. 初始化: b0 (先验信念)
2. 对每个时间步 t = 1 to T:
   a. 提取信念嵌入: h_tilde_i = f(b_{t-1,i}, o_t)
   b. 计算势能: phi_i, phi_ij
   c. 计算信念转移先验: p(b_t | b_{t-1}, o_t)
   d. 推断信念后验: q(b_t | o_t, a_t) (仅训练时)
   e. 计算边际概率: p(b_t,i = 1)
   f. 提取动作嵌入并计算注意力: Z_{t,j}
   g. 预测动作: p(a_t | b_t)
3. 通过ELBO反向传播更新参数
```

## 3. 与Spatial AGI的关系 (Q2)

### 3.1 Spatial AGI研究背景

Spatial AGI（空间通用人工智能）是一个活跃的研究领域，专注于：

1. **空间智能**: 理解和推理三维物理空间
2. **具身智能**: 智能体在物理世界中的感知-运动闭环
3. **时序建模**: 随时间演化的状态和决策

### 3.2 Dynamic Belief Graphs如何融入Spatial AGI框架

#### 3.2.1 时序状态建模的贡献

Dynamic Belief Graphs框架为Spatial AGI提供了**时序信念状态建模**的方法论：

| Spatial AGI组件 | Dynamic Belief Graphs贡献 |
|---------------|-------------------------|
| 世界模型 | 通过信念图编码智能体对环境的内部表示 |
| 决策制定 | 信念驱动的动作选择机制 |
| 长期记忆 | 信念的时间演化作为"认知记忆" |
| 不确定性推理 | 概率图模型框架下的信念推理 |

#### 3.2.2 高风险决策场景的关联

Spatial AGI中的许多关键应用与论文关注的高风险决策场景高度重叠：

1. **自动驾驶**: 需要推理其他道路使用者的意图和信念
2. **机器人协作**: 理解人类操作员的意图和期望
3. **紧急响应机器人**: 预测人类在灾害场景中的行为

### 3.3 技术贡献的可扩展性

论文框架的以下特性对Spatial AGI具有重要价值：

1. **无监督信念学习**: 不需要信念级别的标注，适应于真实世界的复杂场景

### 3.4 潜在研究方向

将Dynamic Belief Graphs与Spatial AGI结合的可能方向：

## 4. 创新点和局限性 (Q3)

### 4.1 核心创新点

#### 4.1.1 创新一：结构化认知轨迹框架

**突破**: 将ToM推理从静态推断扩展到动态轨迹建模

- 传统方法：在每个时间步独立推断信念
- 本论文方法：将信念建模为时间序列，捕捉信念的演化规律

**价值**: 使得ToM推理能够解释"信念如何随时间变化并最终触发行动"

#### 4.1.2 创新二：语义到势能投影

**突破**: 解决了LLM语义表示与概率图模型之间的对齐问题

- 设计了对比学习目标防止语义翻转
- 允许LLM的语言理解能力引导概率模型的更新

**价值**: 为LLM与结构化概率模型的结合提供了可扩展的范式

#### 4.1.3 创新三：成对信念依赖建模

**突破**: 显式建模信念之间的相互影响

- 使用能量函数捕获信念间的强化或抑制关系
- 通过成对势函数学习信念交互结构

**价值**: 更真实地反映人类认知中的信念相互关联

#### 4.1.4 创新四：动作特定自注意力

**突破**: 捕捉"不同信念组合以非线性方式触发不同动作"的复杂性

- 为每个动作计算独立的注意力矩阵
- 允许信念之间的交互因动作类型而异

**价值**: 提高了动作预测的准确性和可解释性

#### 4.1.5 创新五：ELBO联合优化

**突破**: 通过变分推断实现无监督的信念学习

- 不需要信念级别的标注
- 信念学习由动作信号驱动

**价值**: 使方法适用于标注稀缺的现实场景

### 4.2 实验验证的创新

1. **真实世界数据集**: 使用野火疏散调查数据，包含真实的灾难响应决策
2. **多维度评估**: 
   - 单信念预测（Spearman相关）
   - 成对信念结构学习
   - 时间动态一致性（Cohen's d, DTW）
3. **消融实验**: 验证各组件的独立贡献

### 4.3 局限性

#### 4.3.1 局限一：信念维度固定

**问题**: 论文使用6个固定信念维度（K=6），无法自动发现新的信念类型

**影响**: 限制了框架在新领域或新任务上的泛化能力

**可能的改进**: 引入可学习的信念维度发现机制

#### 4.3.2 局限二：二进制信念表示

**问题**: 将信念建模为二进制变量（0/1），无法捕获信念的强度

**影响**: 损失了信念强度的细微变化信息

**可能的改进**: 扩展到连续值信念或序数变量

#### 4.3.3 局限三：计算复杂度

**问题**: 信念边际概率需要枚举所有2^K种配置，当K增大时计算不可行

**影响**: 限制了框架扩展到大量信念维度

**可能的改进**: 引入均值场近似或采样方法

#### 4.3.4 局限四：领域依赖性

**问题**: 框架需要针对特定领域设计信念维度（如野火疏散的6个信念）

**影响**: 跨领域迁移需要重新设计信念模式

**可能的改进**: 开发通用的信念维度发现方法

#### 4.3.5 局限五：LLM依赖性

**问题**: 框架依赖冻结的LLM提取语义嵌入，需要大量LLM API调用

**影响**: 增加了计算成本，且性能受限于LLM能力

**可能的改进**: 使用更小的模型或知识蒸馏

#### 4.3.6 局限六：评估指标间接

**问题**: 信念是潜在变量，ground truth难以获取，使用调查数据作为代理

**影响**: 评估可能不完全反映真实信念质量

**可能的改进**: 设计更直接的信念获取方法

#### 4.3.7 局限七：动作空间有限

**问题**: 实验中的动作空间相对较小（4个中间动作+2个最终决策）

**影响**: 未验证在更复杂动作空间下的有效性

**可能的改进**: 扩展到更大规模的动作空间

## 5. 技术细节深入分析

### 5.1 能量函数设计

#### 5.1.1 理论基础

能量函数方法（Energy-Based Models）是概率建模的另一范式：

```python
p(x) = exp(-E(x)) / Z
```

与直接建模概率不同，能量函数通过惩罚不一致的配置来学习。

#### 5.1.2 本论文的能量函数

论文使用对数势能（log potentials）：

```python
E(b_t) = sum_i log(phi_i) + sum_{i<j} log(phi_ij)
```

这等价于：

```python
p(b_t) ∝ product_i phi_i * product_{i<j} phi_ij
```

即乘法交互模型。

### 5.2 变分推断详解

#### 5.2.1 为什么需要变分推断？

信念bt是离散的二进制变量，后验分布p(b_t | o_t, a_t)需要枚举2^K种配置，无法精确计算。

#### 5.2.2 变分近似的选择

论文使用因式分解的后验近似：

```python
q(b_t | o_t, a_t) = product_i Bernoulli(b_{t,i} | logit_{t,i})
```

这种近似允许高效的采样和梯度计算。

#### 5.2.3 ELBO的双重作用

1. **重构项**: 鼓励推断的信念解释观察到的动作
2. **KL项**: 强制推理后验接近生成先验，确保时间一致性

### 5.3 语义嵌入提取策略

#### 5.3.1 LLM选择

论文使用Qwen-8B作为冻结的LLM：

- 选择原因: 在语义理解和推理任务上性能良好
- 冻结策略: 不微调LLM参数，仅训练投影层

#### 5.3.2 提示设计

对于每个信念，构造两类提示：

```python
# 假设信念存在
prompt_yes = f"Given observation: {ot}. Assuming the person previously believed '{belief_i}', 
              do they still hold this belief? Answer: Yes"

# 假设信念不存在  
prompt_no = f"Given observation: {ot}. Assuming the person previously did NOT believe '{belief_i}',
```
