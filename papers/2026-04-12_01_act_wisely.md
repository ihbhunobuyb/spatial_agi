## 一、核心内容摘要

### 1.1 研究问题

本文旨在解决多模态大型语言模型（MLLMs）在作为智能体（agent）时的**元认知缺陷（meta-cognitive deficit）**问题。具体表现为：

1. **盲目工具调用（Blind Tool Invocation）**：现有的开源多模态智能体（如DeepEyes、Thyme等）即使在仅凭视觉上下文就能回答的问题上，也会频繁调用外部工具
2. **工具过度使用**：如图1所示，现有方法的工具调用率高达80%-98%，但并未带来相应的推理性能提升
3. **延迟瓶颈**：不必要的工具调用引入显著的延迟开销，同时可能引入环境噪声，破坏推理链的完整性

### 1.2 核心贡献

1. **问题定义**：首次系统性地识别了多模态智能体中的"盲目工具调用"失败模式
2. **算法创新**：提出HDPO（Hierarchical Decoupled Policy Optimization）框架，将任务准确性和工具效率解耦为两个独立的优化通道
3. **模型训练**：基于Qwen3-VL-8B训练Metis，在多个基准测试上取得最先进的开源智能体性能
4. **关键成果**：工具调用率从98%降至2%，同时提升推理准确率

## 二、背景与相关工作

### 2.1 多模态大型语言模型（MLLMs）

近年来，多模态大型语言模型在视觉-语言任务上取得了显著进展：

- **早期工作**：LLaVA系列、Qwen-VL系列等，主要关注直接答案生成
- **思维链引入**：借鉴LLM的chain-of-thought reasoning，引入显式的中间推理步骤
- **潜在视觉推理**：最近的工作探索在推理过程中插入连续的视觉表示

然而，这些模型大多是被动的，仅依赖一次性预测，缺乏主动调用外部工具的能力。

### 2.2 智能体多模态模型（Agentic Multimodal Models）

一个新兴的研究方向是赋予MLLMs智能体能力，使其能够在推理过程中主动调用外部工具：

- **工具类型**：图像裁剪、 grounding、图像搜索、代码执行、文本搜索等
- **应用场景**：需要详细检查、迭代证据收集或中间计算的任务
- **现有问题**：已有工作过度强调更强的工具能力和多步骤交互，对工具使用效率关注不足

### 2.3 强化学习在LLM中的应用

- **GRPO (Group Relative Policy Optimization)**：DeepSeekMath提出的基于组相对优势的策略优化方法
- **PPO**：经典的策略梯度方法，使用 clipped surrogate objective
- **现有方法的局限性**：现有RL方法使用标量化的混合奖励，将准确性和工具效率合并，导致优化目标冲突

## 三、方法详解

### 3.1 问题形式化与奖励耦合问题

#### 3.1.1 设定

考虑一个多模态语言模型策略πθ，通过交错链式思维推理和外部工具环境来回答视觉推理问题。给定一个prompt，模型生成G个多轮响应{y₁, y₂, ..., yG}，每个响应yᵢ包含Tᵢ次工具交互后才产生最终答案。

#### 3.1.2 现有方法的奖励耦合问题

现有的GRPO方法使用标量化的混合奖励：

$$R_i^{mix} = R_i^{acc} + α \cdot R_i^{tool}$$

其中：
- $R_i^{acc}$：准确率和格式奖励
- $R_i^{tool}$：工具效率奖励
- α：平衡超参数

然后计算混合优势：

$$A_i^{mix} = \frac{R_i^{mix} - mean({R_1^{mix}, ..., R_G^{mix}})}{std({R_1^{mix}, ..., R_G^{mix}})}$$

**数学分析揭示了三个关键问题**：

1. **梯度纠缠**：共享的分母使两个目标的策略梯度相互关联，准确性更新幅度与工具使用方差成反比
2. **语义歧义**：一个正确但低效的轨迹可能在数学上与一个错误但高效的轨迹产生无法区分的标量奖励
3. **超参数脆弱性**：有效的优化权衡不仅取决于α，还高度依赖于数据依赖的协方差结构

**关键推导**：当α较小时，效率信号在优势归一化过程中被严重抑制。

展开混合优势：

$$A_i^{mix} = \frac{\tilde{R}_i^{acc} + α \cdot \tilde{R}_i^{tool}}{σ_{acc}^2 + 2α Cov(R^{acc}, R^{tool}) + α^2 σ_{tool}^2}$$

其中$\tilde{R}$是中心化奖励。当α足够小，分母主要由准确性方差$σ_{acc}^2$主导：

$$A_i^{mix} = \frac{\tilde{R}_i^{acc}}{σ_{acc}} + O(α)$$

这表明工具效率的梯度贡献不仅被O(α)上界限制，还被通常较大的准确性方差严重衰减。

### 3.2 HDPO：层次解耦策略优化

HDPO通过维护两个独立的优化通道来解决耦合问题。

#### 3.2.1 双奖励设计和解耦优势

**准确性通道**：评估最终响应质量

$$R_i^{acc} = λ_a \cdot R_i^{ans} + λ_f \cdot R_i^{fmt}$$

其中：
- $R_i^{ans} ∈ {0, 1}$：二元正确性分数（由LLM judge评估）
- $R_i^{fmt} ∈ {0, 1}$：格式合规性
- λ_a = 0.9, λ_f = 0.1

标准GRPO优势估计（所有G个rollouts）：

$$A_i^{acc} = \frac{R_i^{acc} - mean({R_1^{acc}, ..., R_G^{acc}})}{std({R_1^{acc}, ..., R_G^{acc}}) + ε}$$

**效率通道**：明确优化执行经济性（工具简洁性）

$$R_i^{tool} = \begin{cases} \frac{1}{T_i + 1} & \text{if } R_i^{ans} > 0 \\ 0 & \text{otherwise} \end{cases}$$

这个逆惩罚使得工具调用次数越多，奖励越低（T=0→1.0, T=1→0.5, 等）。

**条件优势估计**：为避免不正确rollouts污染效率信号，定义合格集Q（仅包含正确响应的索引）：

$$Q = \{j ∈ \{1...G\} | R_j^{ans} > 0\}$$

工具效率优势仅在正确响应之间计算：

$$A_i^{tool} = \begin{cases} \frac{R_i^{tool} - mean({R_k^{tool}}_{k∈Q})}{std({R_k^{tool}}_{k∈Q}) + ε} & \text{if } i ∈ Q \text{ and } |Q| ≥ 2 \\ 0 & \text{otherwise} \end{cases}$$

当正确响应少于2个时，分配零优势以避免跨prompt的无效比较。

#### 3.2.2 层次策略更新

最终HDPO目标：

$$L_{HDPO}(θ) = w_{acc} \cdot L_{GRPO}(A^{acc}) + w_{tool} \cdot L_{GRPO}(A^{tool})$$

由于$A^{acc}$和$A^{tool}$在不同的语义基线上独立归一化，策略梯度干净地分解。每个梯度分量提供针对其各自目标的针对性、正交学习信号，完全消除了之前观察到的破坏性协方差干扰。

#### 3.2.3 隐式认知课程

这种解耦、条件设计的一个显著特性是诱导隐式认知课程：
- **训练早期**：当策略还在与任务挣扎时，合格集Qmostly为空，优化自然由准确性目标主导，迫使模型优先考虑功能正确性
- **训练后期**：随着模型推理能力成熟，更多rollouts有资格进行效率比较（|Q| ≥ 2），平稳地扩展工具简洁性信号

这动态地强制执行两阶段发育轨迹——先学习正确，再学习高效——无需任何明确的手动奖励调度或超参数退火。

### 3.3 训练数据管理

#### 3.3.1 SFT数据管理

SFT语料来自公开可用的工具增强多模态轨迹（DeepEyesV2, V-Interaction, Thyme）。通过三个机制识别和消除低质量样本：

1. **消除幻觉的环境动力学**：现有SFT演示中的一个普遍缺陷是不可执行的代码（语法错误、缺少依赖）与幻觉的工具观察配对。严格在沙箱环境中执行所有代码段，严格丢弃任何表现出执行失败或反馈不一致的轨迹。

2. **隔离真正的工具必要性**：许多现有数据集使用较弱的基线模型注释，这些模型依赖外部工具处理相对简单的查询。建立零样本可解性基线，通过直接推理（无工具访问）评估候选样本上的基线模型（Qwen3-VL-8B）。持续正确解决（pass@8 = 1）的样本被积极过滤掉，确保SFT阶段仅在严格必要时展示工具使用。

3. **多维元认知过滤**：超越单纯的执行正确性，推理链的语义质量至关重要。使用Gemini-3.1-Pro作为自动法官评估轨迹的多个细粒度维度。明确惩罚"盲目工具调用"——如对已清晰的图像应用无意义的图像旋转。

#### 3.3.2 RL数据管理

RL阶段从多个数据集（V-Interaction, Thyme, SenseNova-MARS, DeepEyesV2）管理prompt集。应用以下过滤标准：

1. **环境保真度验证**：通过多模态法官传递原始prompt，评估图像质量、问题清晰度和图像-文本一致性。排除具有损坏视觉输入或严重语义歧义的prompt。

2. **方差感知难度校准**：过于简单（所有G rollouts都解决）或过于困难（所有rollouts都未解决）的prompt产生零方差准确率奖励，导致GRPO中退化的优势估计。经验采样G = 8个rollouts per prompt，严格保留仅表现出成功和失败非平凡混合的样本。

最终RL训练集包含约5K高质量prompts，涵盖多样任务类型：
- 感知相关数据（45%）
- 搜索导向数据（36%）
- 数学/一般推理任务（19%）

## 四、实验

### 4.1 实验设置

#### 训练配置

- **基座模型**：Qwen3-VL-8B-Instruct
- **两阶段训练**：监督微调（SFT）+ 强化学习（HDPO）
- **SFT**：2 epochs, AdamW优化器, cosine学习率衰减, 峰值学习率1×10⁻⁵, 批大小128
- **RL**：HDPO, 批大小128, 每prompt采样G=16个rollouts, 学习率1×10⁻⁶, KL惩罚系数严格设为0, 最大响应长度16384 tokens
- **损失权重**：w_acc = 1.0, w_tool = 0.15

#### 基线模型

- **非工具开源模型**：LLaVA-OneVision, InternVL3-8B, Qwen2.5-VL-7B/32B-Instruct, Qwen3-VL-8B-Instruct
- **纯文本推理模型**：MM-Eureka, ThinkLite-VL, VL-Rethinker, VLAA-Thinker
- **智能体多模态模型**：Pixel-Reasoner, DeepEyes, Thyme, DeepEyesV2, Mini-o3, Skywork-R1V4-30B-A3B

#### 基准测试

**感知和文档理解**：
- V*Bench, HRBench-4K/8K, TreeBench
- MME-RealWorld, SEEDBench2-Plus
- CharXiv（描述性和推理问题）

**数学和逻辑推理**：
- MathVistamini, MathVersemini, WeMath, DynaMath, LogicVista

## 五、与Spatial AGI的关系

### 5.1 空间智能的核心挑战

Spatial AGI（通用空间智能）旨在构建能够理解和推理三维物理世界的AI系统。核心挑战包括：

1. **多尺度空间理解**：从宏观场景到微观细节的统一理解
2. **空间推理**：理解物体之间的空间关系、遮挡、深度等
3. **具身交互**：在物理环境中执行任务的能力
4. **高效工具使用**：在需要时调用工具，在不需要时保持自我依赖

### 5.2 Metis对Spatial AGI的贡献

#### 5.2.1 战略工具使用范式

Metis的核心贡献是培育了一种战略性的工具使用范式，而非盲目的工具调用。这对Spatial AGI至关重要：

1. **空间理解的渐进式深化**：在处理空间问题时，模型需要判断何时需要"放大"查看细节（调用裁剪工具），何时可以直接理解（直接推理）
2. **避免不必要的环境交互**：减少工具调用可以降低引入噪声的风险，保持推理链的完整性
3. **计算资源的有效分配**：在空间推理任务中，不同复杂度的问题需要不同的处理策略

#### 5.2.2 隐式认知课程

HDPO的隐式认知课程机制对Spatial AGI训练有重要启示：

- **阶段一（基础能力）**：首先建立空间理解的基本能力
- **阶段二（效率优化）**：在保证理解准确性的前提下，优化工具使用效率

这与人类学习空间智能的过程类似：先学会"怎么看"，再学会"怎么看更省力"。

#### 5.2.3 数学推理能力的提升

Metis在数学推理任务上的显著提升（WeMath +26.4%）对Spatial AGI具有重要意义：

1. **空间推理与数学推理的关联**：空间智能往往需要几何推理、测量计算等数学能力
2. **代码执行工具的战略使用**：代码执行不仅用于数值计算，还可用于图像处理（裁剪、旋转、增强），这直接服务于空间分析

### 5.3 技术启示

1. **解耦优化策略**：将任务性能和资源效率解耦是训练高效智能体的关键
2. **条件奖励机制**：仅在正确轨迹上优化效率信号，避免学习"快速失败"的捷径
3. **数据质量的重要性**：严格的SFT和RL数据管理对培养战略推理能力至关重要
4. **系统提示的作用**：图6中的系统提示明确定义了工具使用场景，为模型提供了决策边界

## 六、创新点与局限性

### 6.1 创新点

1. **问题定义的创新性**：
   - 首次系统性地识别和定义了多模态智能体中的"盲目工具调用"问题
   - 揭示了现有RL方法在处理准确性和效率权衡时的数学缺陷

2. **算法创新**：
   - 提出HDPO框架，通过解耦优化通道解决梯度纠缠问题
   - 引入条件优势机制，仅在正确轨迹上优化工具效率
   - 隐式认知课程设计，无需手动调度

3. **实证贡献**：
   - 在多个基准测试上取得最先进的开源智能体性能
   - 证明战略工具使用和强推理性能可以同时实现
   - 工具调用率从98%降至2%，颠覆"更多工具=更好性能"的误区

4. **思想贡献**：
   - 将工具使用从"如何执行"提升到"何时 abstain"的元认知层面
   - 为未来的智能体训练提供了新的范式

### 6.2 局限性

1. **评估范围**：
   - 主要在标准学术基准上评估，可能无法完全反映真实世界的复杂场景
   - 未涉及长期规划、开放域任务等更复杂的智能体场景

2. **工具集限制**：
   - 当前仅支持代码执行、文本搜索、图像搜索三种工具
   - 更丰富的工具集（如定位、导航、机器人控制）未被探索

3. **泛化性**：
   - 实验主要在特定数据分布上进行
   - 对分布外场景的泛化能力需要进一步验证

4. **计算成本**：
   - 虽然工具调用减少，但训练过程本身（采样多个rollouts）仍然计算密集
   - 更大规模的模型和数据集上的可扩展性待验证

5. **理论分析**：
   - 虽然提供了数学分析，但更多是直觉性的解释
   - 缺乏对解耦优化收敛性的理论保证

### 6.3 未来方向

1. **扩展到更开放的环境**：将元认知框架扩展到长期规划、开放域任务
2. **更多工具类型**：探索更多空间相关的工具（3D重建、场景理解、定位等）
3. **多智能体场景**：研究多个智能体之间的协调和工具共享
4. **理论分析**：提供HDPO收敛性的理论保证
5. **实际部署**：在实际机器人或AR/VR场景中验证

## 七、总结

本文提出的Metis模型和HDPO框架代表了多模态智能体训练的重要进展。通过解耦任务准确性和工具效率的优化，Metis学会了战略性地使用工具——在需要时调用，在不需要时保持自我依赖。

对于Spatial AGI研究而言，这项工作提供了重要启示：

1. **战略思维是关键**：构建真正的空间智能不仅需要理解"如何做"，更需要理解"何时做"和"何时不做"
2. **效率与性能可以兼得**：消除不必要的工具使用不仅降低延迟，还能提升推理准确性
3. **隐式课程有效**：通过适当的训练设计，模型可以自然地发展出从基础到高效的认知能力

Metis的核心贡献在于将工具使用从机械的执行层面提升到元认知的智慧层面，这正是向通用空间智能迈进的关键一步。

### 混合奖励（现有方法）
$$R_i^{mix} = R_i^{acc} + α \cdot R_i^{tool}$$

### 方差展开
$$Var(R^{mix}) = σ_{acc}^2 + α^2 σ_{tool}^2 + 2α Cov(R^{acc}, R^{tool})$$

### 准确性奖励
$$R_i^{acc} = λ_a \cdot R_i^{ans} + λ_f \cdot R_i^{fmt}$$

### 工具效率奖励
$$R_i^{tool} = \begin{cases} \frac{1}{T_i + 1} & \text{if } R_i^{ans} > 0 \\ 0 & \text{otherwise} \end{cases}$$

### 条件优势（HDPO）
- 准确率优势：对所有G个rollouts计算
- 工具优势：对合格集Q（正确响应）计算

### HDPO总损失
$$L_{HDPO}(θ) = w_{acc} \cdot L_{GRPO}(A^{acc}) + w_{tool} \cdot L_{GRPO}(A^{tool})$$
